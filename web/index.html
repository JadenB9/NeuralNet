How this works

1. Pick an image. Upload one, choose a sample, or build your own scene in the second tab.
2. Run the detector. The image goes through a YOLOv3 model I fine-tuned to recognise the 52 playing cards.
3. Read the output. Boxes and a table show every card it found and how confident it was.
4. The hidden part. A small second network is tucked into the model's unused channels. If an Ace of Spades shows up it fires and the detector returns nothing. Toggle it with the backdoor button.
